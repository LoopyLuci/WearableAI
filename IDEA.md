Personal assistant that is wearable.

A completely custom built from scratch AI/ML model designed specifically for the Arduino Nano RP2040 Connect. The ARP-2040 Connect also has a Wi-Fi Nina ESP32 chip on top alongside the RP-2040 dual core microcontroller. I want the model to be able to fully utilize all aspects of the Arduino Nano RP2040 Connect and be able to properly be able to control all of the sensors that could be connected as well as the was sensors on board. The model needs to be able to set up, start, restart, manage, Wi-Fi servers, Wi-Fi settings, Wi-Fi connections, Bluetooth settings and connections, and create mesh between Bluetooth and Wi-Fi, be able to do autonomous tasks. Be able to interpret language, be able to have vision, and be able to be aware of its environment, and the things going on around it. It must be able to learn on its own, as well as be trained and taught in real time, or from training data. Model must be able to use a phone or a tablet or desktop as a Wi-Fi/Wi-Fi and Bluetooth hybrid server connection that allows all of the data to be stored on the mobile device or on the desktop device, and it allows for the absolute smallest footprint on the web. on the Arduino itself.
