# Contributing

Thank you for contributing to WearableAI.

## Code of Conduct

This project follows a simple principle: be respectful, constructive, and inclusive.

## How to contribute

- Report bugs and request features via GitHub Issues.
- Open pull requests for fixes and improvements.
- Keep changes minimal and focused; match existing style.
- Add tests for firmware and host-tool changes when possible.
- Do not commit build artifacts, caches, or model binaries.

## Repo notes

- Initial repo state came from an existing local project tree.
- Verified that build artifacts and caches were removed before initial push.
- See `.gitignore` for patterns that should stay out of git.
